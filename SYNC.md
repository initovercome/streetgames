# Живая статистика на сайте

Игровой сервер (ресурс `SiteSync`) раз в 10 минут сам отправляет статистику в Worker сайта.
Сайт забирает её с `/api/stats`. Игровой сервер сайт не опрашивает, поэтому посетители его не нагружают.

Что показывается:

- топ по славе и по деньгам (без админов);
- банды по захваченным районам;
- рекорды трасс TimeRacing по классам и рекорды DriftKing — за всё время и за неделю.

## Файлы

| Файл | Что это |
|---|---|
| `worker/index.js` | Worker: `POST /api/push` (от сервера, с ключом), `GET /api/stats` (для сайта), всё остальное — статика |
| `wrangler.jsonc` | Настройки Worker'а: статика из корня репо + KV `STATS` |
| `.assetsignore` | Чтобы `worker/`, `wrangler.jsonc` и прочее не раздавались как файлы сайта |
| `index.html`, `script.js`, `style.css` | Блоки статистики берут данные из `/api/stats`; добавлен раздел «Рекорды» |

## Настройка в Cloudflare (один раз)

1. **KV:** Storage & Databases → KV → Create → имя, например `streetgames-stats`.
   Скопировать его **ID** и вставить в `wrangler.jsonc` вместо `ВСТАВИТЬ_ID_KV`.
2. **Ключ:** Workers & Pages → `streetgames` → Settings → Variables and Secrets → Add →
   тип **Secret**, имя `SYNC_KEY`, значение — ключ из `config.lua` ресурса SiteSync (`Config.Key`).
   Ключ передать лично, в репо его не класть.
3. **Деплой:** если Worker подключён к этому репо (Settings → Builds), он сам пересоберётся после пуша.
   Если сайт заливали руками, то `npx wrangler deploy` из корня репо.

Проверка: открыть `https://streetgames.streetgames.workers.dev/api/stats`.
До первой отправки с сервера там будет `"empty": true`, а после — все данные.

## Лимиты (бесплатный план)

- KV: 1000 записей в сутки. Сервер пишет раз в 10 минут, это 144 записи.
- Чтения кэшируются на минуту.
